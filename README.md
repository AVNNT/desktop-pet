# Desktop Pet

A small desktop pet built with Godot 4.7. Runs as a transparent, borderless window on your desktop.

## Running

```sh
./DesktopPet.sh
```

On other platforms, use the exported binary for your architecture.

## Project layout

```
scenen/       Main and pet scenes
scripts/      GDScript logic
icon.svg      App icon
project.godot Godot project config
```
